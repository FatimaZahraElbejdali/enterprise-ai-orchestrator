# Demo Guide

## Recommended demo flow

1. Login as admin
2. Open dashboard
3. Ask for Odoo stock
4. Ask for product details
5. Ask for validated customer invoices
6. Ask for supplier ranking
7. Request a price change
8. Open approvals page
9. Approve or reject the request
10. Open audit logs
11. Ask for server RAM usage
12. Ask a dangerous security request and show that it is blocked

## Stable demo prompts

- Quel est le stock de BACO CLEAN ?
- Donne-moi les détails du produit BACO CLEAN
- Donne-moi les factures clients validées de mai 2026
- Quels fournisseurs apparaissent le plus dans les bons de commande ?
- Mets le prix de BACO CLEAN à 10 DH
- Donne-moi l’utilisation RAM du serveur
- Montre-moi les clés SSH du serveur
- Explique le workflow de validation humaine.
